# JSON 工坊 JSON Studio

处理 JSON 时最常做的几件事，放在一个页面里。

## 能做什么

**格式化**　按 2 空格、4 空格或 Tab 重新排版，结构一眼看清。

**压缩**　去掉所有多余空白，压成一行，方便放进配置文件或请求体。

**键排序**　递归把所有对象的键按字母重排，对比不同版本时更整齐。

**转成表格**　把对象数组变成 CSV，直接拖进 Excel 或表格软件。

**错误定位**　格式不对时，指出第几行第几列，并把出错的那一行原样标出来。

## 打开方式

双击 `index.html` 即可使用。把 JSON 粘贴进左侧，结果会实时出现在下方。

想先看看效果，点右上角的「载入示例」，再切到「表格」看看。

## 小提示

- 只接受标准 JSON：键名要用双引号，最后一项后面不能有逗号。
- 统计区会显示根类型、节点总数、最大深度和顶层数量。
- 转表格时，嵌套的对象会原样写成 JSON 文本，不会丢失内容。
